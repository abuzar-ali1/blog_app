# Blog App

Blog App is a full-stack blogging platform that allows users to create, read, update, and delete blog posts. Built with TypeScript for a robust frontend and Python for reliable backend services, it provides a seamless blogging experience.

## Features

- Create and publish blog posts
- Read and browse multiple articles
- Edit and update existing posts
- Delete posts
- Clean and intuitive user interface
- Fast and responsive performance

## Technologies Used

- **TypeScript** — Frontend application and type-safe logic
- **Python** — Backend API and data processing
- **Modern web standards** — Responsive design and user experience

## Getting Started

1. Clone the repository.
2. Install frontend dependencies (Node.js/npm).
3. Install backend dependencies (Python/pip).
4. Configure environment variables.
5. Start the development servers for both frontend and backend.
6. Open your browser and begin blogging.

## Usage

- Navigate to the home page to view published posts
- Click "Create Post" to write a new article
- Use the edit feature to modify existing posts
- Delete posts you no longer need
